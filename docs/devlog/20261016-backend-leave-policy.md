# 2026-10-16 순수 연차 산정기

- 작업: 검증 작업, 검증 작업 보조. 담당: 백엔드팀 엑셀처리담당.
- 소유 파일: `LeavePolicy.java`, `LeavePolicyTest.java`, 이 개발일지 세 파일만 작성했다.

## 구현 계약

- `public final LeavePolicy`에 공개 `Period(start,end,granted)` record와 `public static calculate(hireDate,today)`를 제공한다. Spring, DB, 시스템 시계에 의존하지 않는다.
- 기간은 입사기념일부터 다음 입사기념일 전날까지이며 종료일을 포함한다.
- 경과 연도의 시작과 다음 기념일 모두 원입사일의 `plusYears(n)`으로 계산한다. 2월 29일 입사자는 평년에 2월 28일을 적용하고 다음 윤년에 2월 29일로 복귀한다.
- 첫해는 원입사일 `plusMonths(1..11)` 중 오늘 이하인 날짜 수만큼 부여한다. 짧은 달의 조정된 날짜를 연쇄 계산하지 않는다.
- 만 1년 이후 부여량은 `min(25, 15 + (n-1)/2)`이며 BigDecimal 정수 값으로 반환한다.
- 미래 입사는 입사일부터 첫 기념일 전날까지의 기간과 0일을 반환한다. null 인자는 즉시 거절한다.

## 테스트 코드 및 실행 상태

- 입사 당일, 미래 입사, 첫 기념일 전날·당일, 가산 주기 및 25일 상한을 검증하는 테스트를 작성했다.
- 2월 29일 입사의 평년 기념일, 윤년 복귀 전날·당일, 다음 윤년 복귀, 일반 2월 28일 입사를 포함했다.
- 1월 31일·8월 31일·2월 29일 입사와 짧은 달의 월별 경계, 첫해 11개 발생 경계 전날·당일·다음날을 검증한다.
- 담당 지시에 따라 빌드·테스트는 실행하지 않았다. 담당의 일괄 실행 결과로 통과 여부를 확인해야 한다.
- 소유권 외 파일 수정 및 Git 커밋을 하지 않았다. 완료 보고 후 세 파일의 소유권을 담당에게 반환한다.
