## 2. 잘 반영된 점 (확인됨)

- 셸: 60px 상단 바 + 브레드크럼, 어두운 사이드바, 활성 메뉴 배경 + 왼쪽 흰 막대, 관리자 메뉴 순서(대시보드→…→감사 로그→내 정보).
- 대시보드: 차트 제목 "최근 12개월 월별 입사·퇴사 건수", 부제 "월별 건수(월말 인원 아님) · 미래 날짜 제외", 분포 제목 "재직자 현재 부서별/직급별 분포"와 "과거 시점 분포 아님", 기준일(KST), y축 정수 눈금(0/8/16/24/32), 범례 글자, "수치 표로 보기", 상태 집계와 날짜 집계의 차이 설명 문구.
- 수정 화면: 소속이 점선 읽기 전용 블록 + "발령 등록하러 가기", 필수 표시 안내, 기본 정보/소속/계정 섹션 구분. 모바일은 저장이 위인 세로 버튼.
- 발령 대화상자: 현재 소속 표시, "(현재)" 기본값, 날짜 규칙 안내, 되돌림 안내 띠, 첫 입력 포커스 링 보임.
- 발령 이력: 발령일 최신순 설명, 기록 시각(KST), 스냅샷 캡션 "발령 당시 정보", 모바일 카드 전환.
- 목록: "현재 조건 전체 31명 · 페이지 구분 없음" 문구로 내보내기 범위 명시, 상태 배지 색+글자.
- 가져오기: 전부 취소 규칙, 문자열 셀, 5MiB·1,000행·수식 불가 안내, 실패 시 "등록이 모두 취소되었습니다", 엑셀 실제 행 번호 표.
- 감사 로그: 가져오기·내보내기 대상 "사원 · 여러 사원(개별 대상 없음)", 로그인 대상 "해당 없음", 스냅샷 캡션, "변경 전: 해당 없음 · 변경 후: 해당 없음", 오류 코드·오류 수, 기간 [from,to) 설명 "시작일 00:00부터 종료일 다음 날 00:00 전까지", 결과 배지 "! 실패".
- 부서: 삭제 제한 설명이 "과거 발령 이력" 참조를 포함.
- 모바일 필드·버튼 높이 44px 내외, 1열 폼.

## 3. 지적 사항

심각도: **높음** = 내용을 가리거나 읽을 수 없는 문제, 또는 동작 오해 소지 / **중간** = 명세와 다르고 이해를 떨어뜨림 / **낮음** = 다듬기.

명세와 다르지만 **수용**(지적 아님):
- 내보내기·양식·가져오기 버튼을 페이지 머리 대신 목록 위 별도 줄에 펼쳐 둔 배치. 범위 문구가 붙어 있어 의미 전달이 됨.
- 감사 로그를 표 대신 카드 목록으로 구현. 단, 스크린 리더에서 열 구분이 사라지므로 각 카드 안에 시각적으로 숨긴 라벨(시각·행위·행위자→대상·결과)을 둘 것을 권장(미확인 사항 U-3).
- 대시보드 KPI 카드에 상태 색 점이 없는 것(글자로 상태가 구분됨).
- 이번 달 입퇴사를 정보 띠 형태로 표시.
