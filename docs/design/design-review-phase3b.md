## 5. 미확인 범위 (결함 아님)

- **실측 대비:** 배지·버튼 색은 토큰 계열로 보이지만 픽셀 대비를 측정하지 않았다. 비활성 버튼(#9 #10 #19)의 대비도 측정하지 않았다.

- **실제 API 화면:** 전부 목업이다. 실제 Compose 백엔드 응답, 실제 409·403·404 메시지는 확인하지 않았다.
- **캡처가 없는 화면·상태:**
  - 조직·직책: 부서 계층 편집(조직 관리)과 그 409 4종, 직책 수정·삭제 오류, 휴직 배지
  - 급여 설정: 미설정(404)
  - 급여 월: 생성 오류(SALARY_SETTING_MISSING·ALREADY_EXISTS·BUSY·VALIDATION), 재계산·확정 후 화면(CONFIRMED 월 상세, 버튼 없음)
  - 명세: 본인 명세 목록(`/payslips/me`), 명세 404
  - 평가 본인 화면: 공개 전 화면(SELF_SUBMITTED·MANAGER_DRAFT), CLOSED 미완료(incomplete)
  - 평가 관리: 주기 열기·종료 확인 모달, 평가자 재배정 모달과 초안 삭제 경고, 평가 409·403·404 안내
  - 공통: 빈 상태, 권한 없음
- **긴 모바일 이미지 미확인 구간:** #22 1800–2653, #23 1800–3511. 축소 보기로 본 이미지(#1 #2 #18 #26 #32 #34 #39)는 작은 글자를 원본 해상도로 읽지 않았다.
- **모달 하단:** #4 #25 발령 모달 버튼, #29 모바일 초안 명세 목록.
- **환경:** 태블릿 폭, 200% 확대.

- **실제 API 화면:** 전부 목업이다. 실제 백엔드 응답과 오류 화면은 확인하지 않았다.
  - 부서·직책 409
  - SALARY_SETTING_MISSING·ALREADY_EXISTS·BUSY
  - 평가 STATE_CONFLICT·CYCLE_CLOSED·REVIEWER_INVALID
  - 명세 404
- **캡처가 없는 상태:** CLOSED 미완료(incomplete), 휴직 배지, 빈 상태, 권한 없음, 급여 설정 미설정(404), 주기 열기 모달, 재배정·주기 종료·최종 확정 버튼의 활성 색.
- **다시 열지 않은 41장:** 2차 판정을 유지했을 뿐 새 캡처로 회귀를 확인하지 않았다. 축소 보기 이미지는 원본 해상도로 읽지 않았다.
- **환경:** 태블릿, 200% 확대.
