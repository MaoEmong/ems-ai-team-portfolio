# ADR 0110: 데모급여 월 잠금과 확정 스냅샷
산식 DEMO_V1은 총지급의450/350/300bps 공제를 각각 BigDecimal HALF_UP 원단위로 반올림해 합산한다. 기본급/수당 각각0~10억, JSON 정수로 안전범위를 지킨다. 포트폴리오용 데모이며 실제 세법·4대보험 산정이 아니다. 다운로드는 승인 범위에서 제외했다.
월 단위 GET_LOCK(...,0)과 행잠금을 함께 사용한다. named lock을 얻지 못하면 즉시 PAYROLL_BUSY다. 잠금은 트랜잭션과 같은 JDBC 연결에 잡고 afterCompletion에서 COMMIT/ROLLBACK 이후 해제한다. 설정누락·감사실패 시 월/명세 전체를 롤백한다.
대상은 입퇴사일의 월 교집합이다. 현재 상태를 과거월 재직이력으로 추정하지 않고 생성시점 설정/소속을 스냅샷한다. 일할계산 없음. 초안 재계산은 현재 대상 전체교체, 확정 후 수정/재생성 금지. 이름/소속/금액/공제율/산식/처리자 스냅샷과 월 확정정보를 보존한다.
사원은 본인 CONFIRMED만 조회하고 나머지는404. 감사에는 월/ID/상태/건수만 남기며 금액은 제외한다.
검증: 항목별 반올림·최댓값, 설정누락/실패원자성, named lock 경합/동시 확정, 스냅샷 불변·타인404를 테스트한다. 최종 결과는 개발일지 참조.
