# ADR 0105: 엑셀 전부 취소 및 파일 안전 정책
- 상태: 채택, 2026-10-16
- 근거: 사용자 전부 취소 요구, 2단계 회의 및 .
## 결정
Apache POI 5.5.1로 xlsx만 받는다. 공식 배포 근거: https://poi.apache.org/download.html .
파일5MiB, 데이터1000행, ZIP 해제 총20MiB/엔트리10MiB를 제한하고 실제 압축 해제 스트림으로 크기를 확인한다. 암호화·손상·잘못된 시트/헤더는 IMPORT_INVALID_FILE이다. 완전히 빈 행은 건너뛰되 실제 행 번호를 반환한다.
사번·날짜·비밀번호는 문자열 셀 필수이며 숫자·날짜 셀 자동변환을 거절한다. 양식에 해당 열 텍스트 서식을 지정한다. ID만 양의 정수 숫자/문자열을 허용하고 입력 공백을 자동 제거하지 않는다. 수식은 실행하지 않고 거절한다.
형식 검증 뒤 DB 참조·중복을 검사하고 한 트랜잭션으로 계정 포함 전체 등록한다. 파일 내부 중복도 실제 employee 열의 charset/collation을 읽어 MySQL JSON_TABLE 및 윈도 집계로 비교한다. Java 소문자화만으로 MySQL의 악센트·공백 비교를 흉내 내지 않는다. 스키마에서 읽은 식별자는 안전 문자 집합을 검증한 후 SQL에 사용하고 입력값은 바인딩한다.
검증 후 동시 제약 충돌은409 IMPORT_CONFLICT로 전체 취소하며 가짜 행 번호를 만들지 않는다. 오류에는 입력 원문을 넣지 않는다.
내보내기는 필터 결과 전체,10000행 상한이며 일부만 내보내지 않는다. xlsx 모든 셀은 문자열, CSV는 UTF-8 BOM·CSV 인용과 수식 시작문자 방어를 적용한다. 비밀번호는 업로드 전용이며 내보내지 않는다.
## 역할 분리와 검증
Codex 파일 담당은 순수 코덱/안전 검증/단위 테스트를 작성하고 담당은 DB·감사·트랜잭션·통합 검증을 담당했다. 빌드·테스트는 담당만 통합 실행한다. 정상 다중행, 행 중간 오류, 후반 DB 충돌, 실제 collation 중복, 수식/셀 형식/ZIP 한도, CSV BOM, 양식 서식을 검증한다.
