# ADR 0106: 근태 판정은 조회할 때 계산
상태: 채택, 2026-10-16 검증 완료. 결정 정책의 출처는 3A 설계 검토 및 후속 계약이다.
서울 서버 시각을 초 단위로 저장하고 조회 시 현재 APPROVED 휴가와 함께 지각·조퇴를 계산한다. 원본 출퇴근 시각과 corrected를 보존하며 자동 결근/퇴근을 만들지 않는다. 오전 반차 출근14시, 오후 반차 퇴근14시, 양쪽 반차/종일은 LEAVE이며 두 판정은 false다. leaves 배열로 두 반차를 모두 반환한다.
이 방식은 승인·취소·정정 이후 판정이 오래된 값으로 남는 것을 막는다. 정정은 사원 행 잠금 후 변경·감사·알림을 원자적으로 저장한다. 근무시간 합계·점심공제·공휴일·야간은 데모 범위 밖이다.
검증: 최종 MySQL 3A 14사례 중 정각/1초 경계, 반차와 양쪽 반차, 종일휴가 출근 거부, 정정·감사·알림, 날짜 제약을 통과했다. 신규/기존 Compose 모두 실제 출퇴근·정정과 휴가 반차 기준 표시를 확인했다. 실제 브라우저 화면 검수는 문서QA 담당이다.
