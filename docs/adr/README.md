## 작성 템플릿

```markdown
# NNNN. 제목
- 날짜:
- 상태: 제안 / 채택 / 대체
- 결정 주체 및 근거:
## 배경
## 고려한 대안
## 결정과 근거
## 결과와 한계
## 검증 및 관련 문서
```

기존 결정을 바꿀 때 원문을 지우지 않고 후속 ADR과 대체 관계를 남깁니다. 백엔드의 JWT/Flyway ADR과 프론트 ADR은 각 팀 작성 후 등록합니다.
