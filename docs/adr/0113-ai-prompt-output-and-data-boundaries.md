# ADR 0113: AI 프롬프트·출력과 데이터 권한 경계
설계 검토에서 확정한 계약 v1.0 기준이다. AI-01은 기존 검색5필드 제안만 반환하며 검색은 사람 확인 후 기존 API에서 수행한다. SQL·도구 호출·임의 URL 접근은 제공하지 않는다. 직원 행 자체를 전송하지 않는다.
AI-02는 기존 상세 권한과 FINALIZED 검사를 먼저 통과해야 한다. 권한 밖·다른 ADMIN·미확정이면 제공자 호출0이다. 항목 이름과 코멘트만 추출하고 점수/등급/인적 식별자는 전송하지 않는다. 결과는 저장하거나 평가에 적용하지 않는다.
AI-03은 저장소의 소수 합성 규정만 근거로 사용하며 문서ID/버전/절과 정확한 부분 문자열 발췌를 확인한다. 인용이 없거나 맞지 않으면 모델 답변을 버리고 INSUFFICIENT_EVIDENCE를 반환한다. 이 검사는 답변의 의미적 정확성을 보장하지 않는다.

ems-ai-v1 템플릿은 질문·코멘트·카탈로그·규정 본문을 비신뢰 데이터로 지정한다. 출력 JSON 중복 키·후행 토큰·미정의 필드·잘못된 타입·ID·길이·바이트 상한을 거절한다. 틀린 필터를 보정해서 성공시키지 않는다. 템플릿 지시만으로 주입 방어를 보장하지 않으며 권한·실행 가능 작업·스키마 검증을 함께 제한한다.
HTTP 봉투128KiB를 읽기 중 제한하고 모델 JSON64KiB·본문16KiB·평가20항목/코멘트12000자를 적용한다. 원문 입력을 오류나 로그에 넣지 않는다. 자유 텍스트에 포함된 개인정보를 자동 익명화했다는 보장은 하지 않는다.

감사 AI_INVOKE는 actor와 feature/provider/model/promptVersion/durationMs/errorCode만 기록한다. before/after/대상은 null이다. DB에 AI 결과·원문 프롬프트를 저장하지 않으며 기존 VARCHAR action을 확장하므로 새 Flyway는 필요 없다. V1~V4는 변경하지 않는다.
Mock/HTTP 계약/MySQL/실제 제공자/Compose/Chromium/디자인 검수는 별도 증거다. 최종 결과는 4단계 개발일지를 참조한다.

최종 자동검증: 단위·컨트롤러141/MySQL73 통과(실패·오류·스킵0). Mock 실제 HTTP와 실호출 미실행 사유는 [개발일지](../devlog/20261016-backend-phase4-ai.md) 및 backend/verification/20261016-phase4-*.json 참조. 실제 제공자 품질 검증으로 해석하지 않는다.
