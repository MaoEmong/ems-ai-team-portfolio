# ADR 0109: 조직 잠금과 직책 발령
설계 검토 승인 의 계약을 따른다. 조직도는 평탄 배열·최소 사원 필드만 반환한다. 부서 계층 변경과 삭제는 organization_lock 단일행→부서 순서로 직렬화하고 READ_COMMITTED에서 부모 체인을 확인한다. 동시 상호이동으로 순환이 생기는 것을 방지한다.
직책은 직급과 별도 카탈로그다. 발령의 changeJobTitle=false는 유지, true+ID는 지정, true+null은 해제. 직책만 변경하는 발령을 허용하고 전후 이름/ID를 스냅샷한다. 기존 요청/엑셀양식은 유지한다. 일반 PUT의 생략/null/동일직책은 유지하고 다른 값은 APPOINTMENT_REQUIRED다.
퇴사는 현재 직책만 같은 트랜잭션에서 해제하고 EMPLOYEE_RETIRE 전후에 기록하며 별도 발령을 만들지 않는다. 현재/과거발령 참조 직책은 삭제하지 않는다. 직책은 권한이나 휴가 결재자를 바꾸지 않는다.
검증: MySQL 동시 계층 이동·직책 발령 호환·퇴사 강제 실패 롤백 테스트를 작성했다. 최종 실행 결과는 개발일지로 확정한다.
