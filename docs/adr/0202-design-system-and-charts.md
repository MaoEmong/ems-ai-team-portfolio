# ADR 0202: 디자인 시스템과 인라인 SVG 차트

- 날짜: 2026-10-16
- 상태: 채택
- 근거: 사용자 요청에 따른 설계 검토 엔진 배분 결정, 검증 작업, Claude 디자이너 검증 작업 산출물

## 맥락과 결정

Claude 디자이너가 docs/design/design-system.md, screens.md, mockups.html을 작성했다. Codex 담당은 그 규칙을 frontend/src/design.css와 화면에 구현한다. 색·글꼴·간격·포커스·상태를 CSS 역할 토큰으로 통일하고 1단계 화면에도 함께 적용한다. 시스템 글꼴을 사용해 외부 폰트 요청을 추가하지 않는다.

관리자 첫 화면은 대시보드, 일반 사원은 내 정보다. 차트는 별도 라이브러리 없이 인라인 SVG 막대 차트와 CSS 분포 막대를 사용한다. 12개월 두 계열과 현재 분포는 고정된 비교 작업이므로 이 정도 구현으로 요구를 충족한다고 Codex가 판단했다. 차트마다 제목·범례·수치 표를 제공하고 색만으로 의미를 구분하지 않는다. 표의 서버 값과 차트가 같은 응답을 사용한다. 월말 인원이나 과거 조직 분포를 추정하지 않는다.

## 대안과 영향

일반 차트 라이브러리는 툴팁·확대·복잡한 시계열이 필요할 때 재검토한다. 이번 구현은 축·빈 상태·모바일 레이아웃을 직접 검증해야 한다. 숫자 표가 차트의 접근 가능한 대안이며, 분포 비율과 합계처럼 화면에서 계산한 값은 서버의 원본 수치에서만 도출한다.

디자인의 원저자는 Claude, 구현과 테스트는 Codex다. 구현 후 Claude가 데스크톱·모바일 캡처를 보고 남긴 지적과 Codex 반영 결과를 design-review 문서에 연결한다. 엔진의 일반적인 성능 우위나 측정하지 않은 효과를 주장하지 않는다. 실제 검수 결과는 개발일지와 디자인 검수 기록을 따른다.
