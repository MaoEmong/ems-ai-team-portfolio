# ADR 0204: 알림 폴링과 계정별 요청 격리

- 상태: 채택
- 결정자: Codex 담당(3A 설계 검토 계약의 구현 선택)
- 날짜: 2026-10-16

## 배경

3A 계약은 화면이 보일 때 30초 폴링, 화면 복귀·업무 처리 후 즉시 갱신을 요구한다. 이전 계정 요청이 새 로그인 이후 완료되면 알림 노출이나 401 처리로 새 토큰 삭제가 발생할 수 있다.

## 결정

useNotifications는 사용자 ID별 effect를 생성하고 종료 시 AbortController, 타이머, 이벤트 리스너를 정리한다. abort를 무시하는 목업·전송 계층에도 안전하도록 live 플래그로 이전 effect 응답을 폐기한다. 같은 계정의 겹친 조회는 요청 순번으로 최신 요청만 반영한다. 스냅샷 owner가 현재 사용자와 다르면 렌더 즉시 빈 상태를 반환한다.

목록과 미읽음 수는 함께 조회한다. 숨은 탭에서는 주기 조회를 생략하고 visibilitychange 및 ems:work-updated에서 다시 조회한다. 업무 처리 API의 성공 뒤에 이벤트를 보내며 알림 생성은 서버 책임이다. 단건 읽음은 POST, 모두 읽음은 화면에서 확인한 대상 ID 경계 upToId를 전송한다.

공통 API의 401 처리는 요청 시작 시 토큰과 현재 sessionStorage 토큰이 같을 때만 로그아웃 이벤트를 발생시킨다. 이전 세션의 실패가 새 세션을 삭제하지 않는다. 이 비교는 서버 인가를 대체하지 않는다.

## 검증과 한계

알림 폴링/가시성/업무 이벤트, 읽음/upToId, 계정 전환 후 늦은 응답 폐기/로그아웃 캐시, 이전 세션401 보호를 검증한다. 읽음 성공은 서버의 updatedCount를 표시하고, 읽음 실패는 별도 오류로 안내한다.

Claude 1차 지적 반영 후 검증 작업에서 새로 실행했다. 2026-10-16 15:36 KST `npm run typecheck` PASS, 15:36:37 `npm test` 7파일97/97 PASS(기존45개 포함 단일 실행), 15:36 `npm run build` PASS, 15:37 승인 셸 `npx playwright test --reporter=list` 5174 목업 Chromium6/6 PASS다. 기존2개·2단계 데스크톱/모바일2개·3A 데스크톱/모바일2개를 포함한다. 24장 재촬영 후 같은 Claude 디자이너 검증 작업가 실제 열어 재확인했고 높음·중간 잔여0을 판정했다. 이후 코드 변경은 없고 문서만 최종화했으므로 위 결과가 최종 소스에 유효하다. 수정 전95/95·6/6 또는 늦게 반환된15:30대 결과를 최종 수치로 이월하지 않았다.

Playwright 목업 서버는 실제 Compose5173과 분리해5174를 사용한다. 최초 기본 셸 실행은 WebServer 경고 이후 응답이 멈췄으나 근본 원인은 확정하지 못했다. 설계 검토 허용 후 Ctrl-C로 종료하고 승인 셸에서 DEBUG=pw:webserver를 켜 재실행해 Vite HTTP200·테스트6/6·서버 종료 로그를 확인했다. 승인 셸에서 정상 동작했다는 사실을 기록하며 ACL이나 네트워크를 근본 원인으로 단정하지 않는다.

구현·자동검증은 Codex, 디자인 시안과 실제 이미지 검수는 Claude UIUX디자이너가 맡는다. 실제 백엔드 E2E는 미실행이며 문서QA가 담당한다. 서버 알림 생성 원자성·수신자 인가·DB 잠금은 목업 검증으로 보증하지 않는다. 디자인 검수 범위와 지적 반영은 docs/design/design-review-phase3a.md에서 별도로 기록한다.

사원 식별 표시는 `frontend/src/attendance.tsx`의 `EmployeeIdentity`가 기존 GET `/employees/{id}`를 사용하며 월별 근태·정정 모달 및 `frontend/src/leaves.tsx` 결재 필터에 재사용한다. 이름·사번·부서·직급을 확인하는 표시 변경이며 새 API는 없다. 미래 정정의 계약 근거는 `docs/api/phase3a-api.md`의 '날짜는 입사일~오늘', '시각은 해당 서울 날짜 안·미래불가'다. 화면의 미래 버튼 숨김과 실제 서버 거절은 구분하며 실제 거절·불변성은 QA 확인 사항이다.

잔여 사항: 디자인 재확인의 낮음 N-01~07을 Codex 담당이 근거·위험과 함께 수용했다(검수 문서§8). 실측 대비·스크린리더·실제 API 화면과 일부 상태 캡처는 미확인이다. ExcelJS 목업 파일 청크929.39kB의 빌드 경고는 남아 있다. 실제 Compose는 사용하지 않았고, 최종 Chromium 종료 후5174 Listen 없음도 확인했다.

추가 diff-check는 api.ts/mock-phase2.ts/mock.ts의 EOF 빈 줄3건으로 exit1이었다. 실행 검증과 구분해 비기능 스타일 잔여로 인계하며 통과라고 기록하지 않는다. 검증 후 코드는 변경하지 않았다.
