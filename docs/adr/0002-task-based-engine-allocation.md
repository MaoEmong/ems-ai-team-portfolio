# 0002. 작업 성격별 엔진 배분

- 날짜: 2026-10-16
- 상태: 채택
- 결정 근거: 사용자 발언과 1단계 종료·2단계 착수 회의의 설계 검토 결정

## 배경

사용자는 "코덱스가 코딩작업은 잘한다고 생각하지만 디자인 작업은 다른 ai가 낫다고 생각하거든", "물론 이미지 생성은 코덱스가 좋긴 해"라고 설명하며 역할별 도구 활용을 요청했습니다. 이는 사용자의 선호·판단이며 모델 성능 비교 실험의 결론이 아닙니다.

## 대안과 결정

기존처럼 Codex가 디자인과 구현을 함께 맡는 방안과 역할을 나누는 방안을 검토했습니다. 설계 검토에서 디자인 시스템·시안·스크린샷 검수는 Claude Code가 수행하고, Codex는 구현·테스트·통합 검수를 맡도록 결정했습니다. 필요한 이미지 생성만 Codex로 수행하며 불필요한 이미지를 만들지 않습니다. Claude Code는 설계와 최종 문서를 교차 검토합니다.

## 실제 수행 근거

[디자인 검수 기록](../design/design-review-phase2.md) 7절에 따르면 Claude 시안→Codex 구현→Claude 이미지 검수 3회→Codex 반영 순서로 진행했습니다. 총 28건의 지적은 해결 24건, 부분 반영 후 수용 1건, 유지·대안 수용 3건으로 기록되며 높음·중간 잔여는 0건입니다. 최종 30장 중 변경 관련 8장을 3차에 직접 재확인하고 나머지는 2차 판정을 유지했습니다. 모바일 상단 바 정렬, 오류 메시지 중복 제거, 확인 대화상자와 복귀 링크 등이 기록된 변경 사례입니다.

## 결과와 한계

디자인 기준과 구현·피드백 연결을 추적할 수 있게 되었습니다. 위 건수는 이 프로젝트의 검수·반영 기록이며 엔진 우열, 작업시간 단축이나 비용 절감 수치를 뜻하지 않습니다. 디자인 검수는 목업 화면 기준이며 실제 API·MySQL 검증, 실측 대비·스크린 리더 검증을 대체하지 않습니다. 미확인 항목은 원본 검수 기록에 유지합니다.
