# 런타임 advisory 68건의 항목별 도달성 분류

기준: 2026-10-18의 런타임 해결 버전 91개와 OSV 조회(22:29:06~22:29:13 KST). 테스트·빌드 의존성, JDK, 컨테이너 OS는 제외했다. **버전 일치 68건**이며 취약점 재현 68건이 아니다. 다음 세 분류는 현재 소스와 기본 Compose의 정적 조건 판단이다. 조건 미충족은 배포 설정이 달라져도 안전하다는 뜻이 아니다. 판단 불가는 미해결 검토 대상으로 남긴다.

실제 도달 가능은 취약 기능이 현재 애플리케이션에서 활성인 항목이다. 헤더 건은 공식 eager 우회를 적용했으므로 현재 공격 성공을 뜻하지 않는다. 다른 항목은 동적 재현을 수행하지 않았다.

분류 집계: 조건 미충족 58건, 판단 불가 9건, 실제 도달 가능 1건.

## 패치 판단

설계 검토 승인 범위는 실제 도달 가능한 High/Critical에 대한 동일 마이너 내 패치와 전체 백엔드 재검증이다. 이번 실제 활성 헤더 경로는 승인받은 공급자 우회로 완화했고, 의존성 버전 교체는 하지 않았다. 나머지 잠재 파서·전송/환경 경로를 근거 없이 실제 도달 가능으로 올리거나 해소했다고 쓰지 않았다. Docker 엔진 부재로 전체 MySQL 재검증이 불가능한 상태이기도 하다. 이후 패치 검토는 동일 마이너 호환성·공식 고정 버전·전체 테스트 PASS를 갖춰 별도로 진행한다. 마이너·메이저 교체는 수행하지 않았다.
