# 3A 3단계 회의: 프론트 재검증·통합 검수

참석: Claude Code(설계 검토), 프론트·문서QA 담당(Codex). 두 차례 의견 후 설계 검토 결정. 당시 Claude1차22장 지적18건(높음1/중간7/낮음10), Codex D3A-01~08 반영·타입검사만 완료였으며 수정 후 전체 검증은 남아 있었다.

최종 소스 타입·단일 전체테스트·빌드·5174 Chromium을 새로 실행하고24장 등 실제 최종 캡처로 같은Claude가 재확인한다. 추가 코드 변경 시 전체 재검증을 반복한다. 최초18개는 동일ID로 반영/수용근거·재확인에 연결하며 낮음 수용 주체/위험과 미확인을 명시한다.

사원 식별 표시는 기존 GET /employees/{id}만 사용한다. 미래 정정의 계약상 미래불가와 UI버튼 숨김은 구분하고 QA가 실제 ADMIN PUT 거절과 근태·감사·알림 불변을 확인한다. 빈 근태행은 미기록이며 자동결근이 아니다.

조기완료3차는 중간 메시지가 done으로 기록돼 QA가 미완료 프론트 인계 전에 배정된 사건이다. QA는 착수하지 않았다. 시스템 상태와 실제 근거를 분리한다. 설계 검토의 QA착수 통지 후에만 검수, 마지막down·볼륨유지, 일회성safe.directory·세논리커밋 원칙을 유지한다.
